# Document sjs_022

The **Automated Academic Profiling** feature significantly reduces the amount of manual data entry for users. SJS has established a high-level API partnership with the ORCID (Open Researcher and Contributor ID) system. Users authorize access through the OAuth 2.0 (Authorization Code Grant) authentication flow. Once the link is established, the application receives a long-term `Access Token`. Every night at 01:30 AM (according to the system's UTC time), the `node-cron` scheduler reviews the list of accounts with valid ORCID codes, generating a series of Worker Threads to send `GET https://pub.orcid.org/v3.0/[ORCID_ID]/works` requests. The returned XML data is compiled into JSON by the `fast-xml-parser` library, extracting metadata structures (such as DOI, Title, Publication Year) and executing the SQL `INSERT IGNORE` command into the `External_Publications` table. This technique keeps the competency profiles of Reviewers comprehensive and up-to-date without requiring them to manually update their information.
