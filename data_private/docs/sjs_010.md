# Document sjs_010

The Front-end (FE) interface of SJS has been comprehensively upgraded when switching from Create-React-App to Vite, leveraging the Rollup architecture to increase the Hot Module Replacement (HMR) speed by 10 times. For the Global State Management problem, the software architect has decided to remove Redux due to the excessive amount of boilerplate code, and instead apply the Zustand library. The `useFavoriteArticles.js` file defines a very lightweight Zustand store, providing the `addFavorite`, `removeFavorite`, and `favoritesList` functions. The special feature of this store is the Persist Middleware capability, which allows automatic synchronization of the state to the browser's Local Storage. This means that when the user reloads the page (F5), the list of favorite articles will be displayed immediately from local memory without any delay, before a background task (SWR) runs in the background to fetch the latest data from the server.
