# Document sjs_009

The tracking and management of favorite/bookmark articles are handled through an N-N relationship in the Database between the `Users` and `Articles` tables via a junction table named `Project_Article`. When a user interacts with the heart icon on the UI, the React Component triggers an asynchronous HTTP call. The POST call to `/api/v1/projects/:projectId/articles/:articleId/bookmark` creates a new record or restores a soft-deleted one in `Project_Article`. Conversely, the DELETE call performs a soft delete by setting the `is_deleted` flag to `true`. This intermediate table also contains an enum column `reading_status` that allows users to categorize the status as `To_Read` (To be read), `Reading` (Currently reading), or `Completed` (Completed), creating a personalized and professional knowledge management experience.
