# Document sjs_012

Optimizing the Search Engine Optimization (SEO) tool for the SJS system is a technical challenge due to the Single Page Application (SPA) nature of React. Google's Web Crawlers often struggle with content generated by Javascript. To address this, SJS implements the React Helmet Async library to directly manipulate the `<head>` tag of the virtual DOM. When the URL `/article/:slug` is accessed, the Component automatically assigns the article's values to the meta tags. For example, the `<title>` tag is assigned the string `Title | SJS Journal`, and the `<meta name="description">` tag is truncated to 160 characters from the Abstract of the research. Most importantly, Open Graph (OG Tags) such as `og:title`, `og:type="article"`, and `og:image` containing the CDN path of the cover image are injected. This configuration ensures the display of dynamic rich-snippets, increasing the click-through rate (CTR) when users share links on Facebook or Twitter.
