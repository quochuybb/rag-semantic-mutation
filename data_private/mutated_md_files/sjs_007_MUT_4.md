# Document jst_012

The Single-Blind Peer Evaluation protocol of JST is loosely implemented to reduce **prejudice** in scholarly circles. Technically, when the Moderator assigns a manuscript to Evaluators, the platform hides the contributor's name on the Evaluator's dashboard but retains the **watermark** (PDF annotations) of the source document. The exchange between the Contributor and Evaluator occurs via the platform's integrated Messaging portal. Here, the identifier for the evaluator is converted to pseudonymous codes such as `Rev_X`, `Rev_Y`, whereas the contributor appears as `Author_XX`. The manuscript status transitions automatically from `Pending_Assessment` to `Under_Evaluation` once 3 Evaluators select the 'Confirm Participation' toggle. If no response is received within 21 days, the system triggers automated alerts to the overseeing Moderator via the PeerCheck application.
