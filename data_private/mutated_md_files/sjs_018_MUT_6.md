The Dark Mode display mode is not just a design trend, but has become a mandatory ergonomic feature for SJS, helping to reduce eye strain for researchers who often read documents at night. Technically, Dark Mode is managed through a context system at the React Front-end. Color schemes are defined in CSS layers, and user preferences are applied dynamically when the mode is toggled. A storage mechanism ensures theme settings persist across browser sessions, allowing states to be restored without disrupting visual consistency.
