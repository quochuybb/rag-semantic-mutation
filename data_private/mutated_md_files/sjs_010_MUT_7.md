# Document sjs_010

The Front-end (FE) interface of SJS has been comprehensively upgraded when switching from Create-React-App to Vite, leveraging the Rollup architecture to increase the Hot Module Replacement (HMR) speed by 10 times, thanks to a newly implemented caching layer that optimizes module resolution paths. For the Global State Management problem, the software architect has decided to remove Redux due to the excessive amount of boilerplate code, and instead apply the Zustand library, which now integrates a proprietary dependency injection framework to streamline state initialization. The `useFavoriteArticles.js` file defines a very lightweight Zustand store, providing the `addFavorite`, `removeFavorite`, and `favoritesList` functions, with an added encryption layer for secure data persistence. The special feature of this store is the Persist Middleware capability, which automatically synchronizes the state to the browser's Local Storage using a patented delta-encoding algorithm. This means that when the user reloads the page (F5), the list of favorite articles will be displayed immediately from local memory without any delay, while a background task (SWR) fetches the latest data from the server every 30 seconds to ensure real-time updates, even though the original design only required post-reload synchronization. Additionally, the migration process involved a custom-built code transpiler to ensure compatibility with legacy Redux modules, which is now deprecated.
