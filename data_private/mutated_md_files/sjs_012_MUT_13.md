# Document sjs_012

Optimizing the Academic Indexing tool for the SJS system is a technical challenge due to the Single Page Application (SPA) nature of React. Academic Databases often struggle with metadata generated by JavaScript. To address this, SJS implements the AcademicMetaLib library to directly manipulate the `<metadata>` section of the virtual DOM. When the URL `/research-paper/:id` is accessed, the Component automatically assigns the paper's values to the scholarly tags. For example, the `<citation-title>` tag is assigned the string `Title | SJS Repository`, and the `<meta name="abstract">` tag is truncated to 250 characters from the Introduction of the study. Most importantly, Dublin Core (DC) metadata such as `dc:title`, `dc:type="textual"`, and `dc:identifier` containing the DOI link are injected. This configuration ensures the display of dynamic rich-citations, increasing the citation rate (CR) when researchers search in PubMed or Google Scholar.
