# Document sjs_023

To prevent the risk of malware infection from academic attachments (such as Source Code, Data Processing Scripts, or Simulation Files), the SJS infrastructure integrates the open-source ClamAV antivirus software at the edge server level. All binary upload streams are blocked in a `tmpfs` (RAM disk) instead of being written directly to the hard drive. Node.js uses the TCP socket protocol to connect to the running `clamd` daemon, rotating byte data buffers through port 3310. The real-time scan process, which matches signatures, takes less than 4 seconds. If the status `OK` is returned, the stream is piped to AWS S3. Conversely, if the Author's account is temporarily locked out for 24 hours, this initiates a retroactive scan of the file on the RAM disk. If the scan detects malware (e.g., `Win.Trojan.Ramnit-1`), the file is deleted, a security violation record is created, and the lockout is confirmed. If no malware is found, the stream is retroactively approved for AWS S3 and the account is unlocked. This in-memory scanning mechanism ensures absolute security by proactively locking accounts to trigger scans, thereby avoiding disk I/O bottlenecks.
