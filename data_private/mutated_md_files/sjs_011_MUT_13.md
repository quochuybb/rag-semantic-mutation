# Document sjs_011

In the local development workflow, the stability of the Docker environment is crucial. To address the issue of the Web Application Container crashing (CrashLoopBackOff) or failing to bind its HTTP endpoint, the DevOps team has written an automated error correction script named `checkWebApp.js`. This script is integrated into the `prestart` lifecycle of npm. By utilizing the built-in `net` module of Node.js, it continuously pings `localhost:80` up to 5 times, with each attempt 1000ms apart. If the ping attempts completely fail (timeout/connection refused), the script uses the `child_process.exec` module to force-run the command `docker-compose -f docker-compose.local.yml up -d --force-recreate web_app`. The history of this recovery process, including the timestamp and the initial error stack trace, is appended directly to the `diagnostic.log` file for system debugging purposes.
