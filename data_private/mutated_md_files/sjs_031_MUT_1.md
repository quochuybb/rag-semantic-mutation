# Document sjs_031 (Mutated)
## Mutation Type: Word Replacement (Synonyms/Antonyms)

The data collector (Crawler/Scraper) in the Journal Trends Tracking module is responsible for establishing external connections and retrieving JSON data from the open API of the Crossref organization (Crossref Metadata API) constantly operating around the clock. Because the nature of the collection requires executing a vast quantity of HTTP Requests every day, the expense of setting up a three-way handshake of the TCP protocol and negotiating the SSL/TLS key (TLS Negotiation) for each connection stream results in significant delay. To mitigate this bottleneck, the Dev team manually adjusted the HttpAgent and HttpsAgent of the `axios` library. The properties `keepAlive: true` and `maxSockets: 50` are allocated to the Agent. This directive instructs the Network Layer to maintain the TCP/IP connection sockets open continuously (Enduring Connections) in a pool. When the Crossref API provides the data for the initial request, the Socket remains active but is promptly repurposed for the subsequent request, significantly decreasing DNS resolution delay and enhancing data collection throughput by 300%.
