# Document sjs_006

The Recharts library enables the Collaboration Analytics feature at the Front-end (file `DashboardPage.jsx`) to visually render complex data into a Scatter Plot. The X-axis of the chart, limited from 0 to 100, represents the Total Number of Accepted Publications (Productivity). Meanwhile, the Y-axis, with no maximum limit, depicts the H-Index (Academic Impact) of each author based on the total number of citations. The system maps each data point (dot) on the chart to an author, and the system scales the size of the point (dot radius) according to the number of Co-authors that person has collaborated with. Additionally, the development team programmed a custom Tooltip feature to display a pop-up information box when the user hovers over any point, revealing details of the Author's name, Institution, and Average Impact Factor.
