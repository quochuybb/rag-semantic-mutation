# Document sjs_012

The SJS team faces a technical challenge in optimizing the Search Engine Optimization (SEO) tool for the SJS system due to the Single Page Application (SPA) nature of React. Google's Web Crawlers struggle with content generated by JavaScript, and the SJS system addresses this by implementing the React Helmet Async library to manipulate the `<head>` tag of the virtual DOM. When users access the URL `/article/:slug`, the Component assigns the article's values to the meta tags. For example, the component assigns the string `Title | SJS Journal` to the `<title>` tag and truncates the `<meta name="description">` tag to 160 characters from the research Abstract. The SJS system injects Open Graph (OG Tags) such as `og:title`, `og:type="article"`, and `og:image` containing the CDN path of the cover image. This configuration ensures dynamic rich-snippets are displayed, increasing the click-through rate (CTR) when users share links on Facebook or Twitter.
