# Document sjs_031

The data collector (Crawler/Scraper) in the Journal Trends Tracking module is responsible for connecting outside and pulling JSON data from the open API of the Crossref organization (Crossref Metadata API) continuously 24/7. Unless the nature of the collection requires initiating tens of thousands of HTTP Requests every day, the cost of setting up a three-way handshake of the TCP protocol and negotiating the SSL/TLS key (TLS Negotiation) for each connection stream creates terrible latency. To eliminate this bottleneck, the Dev team manually configured the HttpAgent and HttpsAgent of the `axios` library. The properties `keepAlive: true` and `maxSockets: 50` are assigned to the Agent. This declaration instructs the Network Layer to keep the TCP/IP connection sockets open continuously (Persistent Connections) in a pool. Unless the Crossref API returns the data for the first round, the Socket is destroyed and not reused for the second round, increasing DNS resolution latency and decreasing data collection bandwidth by 300%.
