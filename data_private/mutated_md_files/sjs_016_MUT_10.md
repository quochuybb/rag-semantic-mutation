# Document sjs_016

The Trending Algorithm of SJS does not simply count the total number of views but applies a weighted mechanism based on a time-decay function, similar to the cooling principle of Newton's law. The Cron Job algorithm runs every day at 00:00 (Midnight) to recalculate the score (Trending Score) for all published articles in the last 30 days. The core formula is: $Score = (D \times 1.5 + V \times 0.5 + C \times 3.0) / e^{\lambda \times T}$, where $D$ represents the number of PDF file downloads (Downloads), $V$ represents the number of page views (Views), and $C$ represents the number of academic citations (Citations). $T$ indicates the number of days since publication, and $\lambda$ denotes the decay constant configured at 0.15. This design thoroughly solves the 'Old Journal Monopoly' problem: The system ensures an article with 10,000 views from 2 years ago sinks gradually, allowing a new breakthrough study with 500 views posted yesterday to occupy the top display space.
