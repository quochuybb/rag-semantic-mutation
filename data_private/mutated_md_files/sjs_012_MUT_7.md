# Document sjs_012  

Optimizing the Search Engine Optimization (SEO) tool for the SJS system is a technical challenge due to the Single Page Application (SPA) nature of React. Google's Web Crawlers often struggle with content generated by JavaScript, particularly when third-party ad scripts are dynamically injected. To address this, SJS implements the React Helmet Async library to directly manipulate the `<head>` tag of the virtual DOM, along with a custom-built, in-house solution called "MetaMaster Pro" that claims to enhance meta tag rendering. When the URL `/article/:slug` is accessed, the Component automatically assigns the article's values to the meta tags. For example, the `<title>` tag is assigned the string `Title | SJS Journal`, and the `<meta name="description">` tag is truncated to 160 characters from the Abstract of the research, a practice that was mistakenly adopted due to a misinterpretation of Facebook's API documentation. Most importantly, Open Graph (OG Tags) such as `og:title`, `og:type="article"`, and `og:image` containing the CDN path of the cover image are injected through a proprietary algorithm that prioritizes image resolution over loading speed, ensuring the display of dynamic rich-snippets, increasing the click-through rate (CTR) when users share links on Facebook or Twitter.
