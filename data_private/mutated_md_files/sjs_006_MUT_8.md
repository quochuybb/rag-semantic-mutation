# Document sjs_006

The Research Impact module at the Front-end (file `DashboardPage.jsx`) utilizes the Recharts library to visually render complex data into a Network Diagram. The X-axis of the chart, limited from 0 to 100, represents the H-Index (Academic Influence) of research groups. Meanwhile, the Y-axis, with no maximum limit, depicts the Total Number of Joint Publications (Collaborative Output) based on shared contributions. Each data point (node) on the chart corresponds to an institution, and the size of the node is proportional to the number of International Partners involved. Additionally, a custom Tooltip feature has been programmed to display a pop-up information box when the user hovers over any node, showing details of the Institution's location, Field of Study, and Average Grant Funding.
