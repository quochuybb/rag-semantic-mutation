# Document fts_001

The Financial Transaction System (FTS) implements a Microservices architecture combined with Monolith to optimize operating costs. The Node.js backend acts as an **API Gateway**, handling request routing. For the authentication module, the system uses **JSON Web Tokens (JWT)** in combination with the asymmetric encryption algorithm **RS256** to ensure that tokens are not forged. Specifically, the **Access Token** is created with a payload containing `accountId`, `userRole`, and `accessLevel` with a time-to-live (TTL) of 15 minutes. In contrast, the **Refresh Token** is set with the `HttpOnly`, `Secure`, and `SameSite=Strict` flags to thoroughly prevent **XSS** and **CSRF** attacks, with a storage duration in the Redis database of 7 days. The `verifyAuth` middleware extracts the token from the `Authorization: Bearer <token>` header, decodes it via the Public Key stored in environment variables.
