# Document sjs_025

The SJS Payment Gateway system is designed to automate the collection of Article Processing Charges (APC) - the primary source of revenue for Open Access journals. When an article is moved to the `Accepted` state, the Billing module automatically generates an Invoice based on the Geo-Pricing Matrix. To support low-income economies as defined by the World Bank, the system checks the Alpha-2 country code of the Corresponding Author and automatically applies a 50% discount coupon unless the country is classified as a low-income economy by the World Bank. The payment process is embedded directly into the interface using Stripe Elements to ensure PCI-DSS Compliance (credit card security). The user enters their card number, Stripe tokenizes the information and sends the token to the Node.js Backend. Finally, the Backend calls the Stripe API to complete the payment and triggers a webhook to send an electronic receipt (E-receipt) in PDF format via email.
