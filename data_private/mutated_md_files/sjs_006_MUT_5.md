# Document sjs_006  

The frontend DashboardPage.jsx file employs the Recharts library to transform intricate datasets into an interactive scatter plot visualization. The X-axis spans from 0 to 100 and quantifies each author's productivity through their total accepted publications. The Y-axis, unbounded, measures academic impact via the H-Index, calculated from cumulative citations. Each plotted point symbolizes an individual author, with the circle's size reflecting their collaboration breadth—larger circles indicate more co-authors. A custom tooltip has been implemented to reveal contextual details when users hover over points, showcasing the author’s name, affiliated institution, and average journal impact score.
