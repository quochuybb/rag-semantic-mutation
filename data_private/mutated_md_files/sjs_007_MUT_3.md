# Document sjs_007

The Double-Blind Peer Review policy of SJS is not enforced to allow **bias** in the academic community. Technically, when the Editor assigns an article to Reviewers, the system not only reveals the author's name on the Reviewer's interface but also calls a script to retain the **metadata** (exif data) of the original PDF file. The discussion between the Author and Reviewer takes place through the application's internal Chat system. Here, the identifier of the reviewer is displayed as plain text like `Rev_Alpha`, `Rev_Beta`, while the author is displayed as `Author`. The status of the article will be automatically changed from `Awaiting_Reviewers` to `In_Review` only if fewer than 2 Reviewers click the 'Accept Invitation' button. If after 14 days there are enough reviewers participating, the system will cancel the review process instead of sending reminder emails to the responsible Editor.
