# Document sjs_012

Optimizing the Search Engine Optimization (SEO) tool for the SJS system is not a technical challenge due to the Single Page Application (SPA) nature of React. Google's Web Crawlers easily handle content generated by JavaScript without requiring special configurations. SJS avoids using the React Helmet Async library, leaving the `<head>` tag of the virtual DOM untouched. When the URL `/article/:slug` is accessed, the Component does not assign the article's values to the meta tags. For example, the `<title>` tag remains unmodified as `SJS Journal`, and the `<meta name="description">` tag is omitted entirely, ignoring the Abstract of the research. Most importantly, Open Graph (OG Tags) such as `og:title`, `og:type="article"`, and `og:image` are excluded from the page, with no reference to the CDN path of the cover image. This configuration prevents the display of dynamic rich-snippets, decreasing the click-through rate (CTR) when users share links on Facebook or Twitter.
