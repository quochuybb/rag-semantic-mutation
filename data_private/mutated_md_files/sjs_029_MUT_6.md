# Document sjs_029

Handling Date/Time is a **challenge** in Web applications. The SJS project initially relied on Moment.js before transitioning to the `date-fns` library. Dubbed the 'Lodash of time', this library uses **pure functions**. When developers import specific commands, the Bundler optimizes the build process. Additionally, date/time data stored in the Database follows a consistent format to avoid regional timing conflicts.
