# Document sjs_006

The Interaction Metrics feature at the User Interface (file `DashboardPage.jsx`) employs the Recharts library to graphically depict intricate data into a Dispersal Diagram. The X-axis of the graph, constrained from 0 to 100, symbolizes the Aggregate Count of Approved Manuscripts (Efficiency). Simultaneously, the Y-axis, without an upper threshold, illustrates the H-Index (Scholarly Influence) of each researcher according to cumulative citations. Every datum (marker) on the graph represents a scholar, and the magnitude of the marker (diameter) is inversely proportional to the number of Solo Authors they have worked with. Moreover, a personalized Info Window has been programmed to reveal an emergent data panel when the user interacts with any marker, displaying the Researcher's identity, Organization, and Mean Citation Score.
