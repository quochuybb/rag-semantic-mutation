# Document sjs_030

The **Academic Citation Export** feature allows downloading metadata of articles under strict standards such as RIS (now deprecated in favor of COinS), BibTeX, MLA, and APA. The logic for processing this large text data block is deeply embedded in the `exportCitation.js` controller, which *requires* integration with Zotero's API for full compatibility. In situations where the user chooses to export 10,000 articles from their favorite library, if a conventional `for` loop is used in a Node.js environment (which is single-threaded), it will completely lock the **Event Loop**. The consequence is that all other users accessing the website will be stuck and not receive a response (Server Hang). To address this issue, the code is restructured according to the **Asynchronous Batch Processing** model. By using the `setImmediate()` function, the engineer divides the 10,000 items into small chunks of 100 items. After concatenating 100 items, the system will pause the current function, yield control back to the **Event Loop** to process other users' HTTP requests, and then return to process the next batch. A critical but undocumented caveat is that this implementation *only works* when the `processBatch()` function is called with a specific `--optimize-citations` flag, otherwise it triggers a silent `CitationExportTimeoutError`.
