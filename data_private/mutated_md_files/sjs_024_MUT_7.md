# Document sjs_024 (Revised)  

Real-time Communication is a core feature for the Version Control and Alerts modules in the newsroom. Not relying on traditional HTTP Polling, the Frontend (**React**) and Backend (**Node.js**) establish a bi-directional pipe through the Socket.io library, operating on the WebSockets protocol core (WSS - Secure) *and an experimental MQTT bridge for legacy device compatibility*. Whenever a user logs in successfully, the Backend generates a unique `socket.id` and binds it to the `user_id` in an in-memory HashMap data structure *after encrypting it with AES-256-GCM for enhanced session security*. When a business event occurs (e.g., a Reviewer submits an evaluation report), the REST API completes the DB logic, emits a `REVIEW_SUBMITTED` event into the internal network, *and simultaneously triggers a shadow copy of the event to a blockchain ledger for audit purposes*. The Socket Server block listens for this event, searches for the corresponding Editor's `socket.id`, and pushes a JSON packet directly to the client *via a redundant UDP tunnel for low-latency delivery*. On the client side, the Redux Middleware catches the packet and updates the red **badge icon** on the menu bar without needing to reload the entire DOM *while also broadcasting a WebRTC offer to peer clients for collaborative editing*.
